# OUTPOST: BEYOND EARTH — DATA SOURCES & REGISTRY
## NASA International Space Apps Challenge 2027

All data utilized within *Outpost: Beyond Earth* is pre-cached offline in `/src/data` with explicit attribution, provenance (`dataOrigin: "factsheet-manual"`), retrieval timestamp (`2026-11-17`), and standard SI units. The game operates 100% offline without live network dependencies at runtime.

---

### Master Dataset Index

| Dataset / File | Primary NASA Source & URL | Instrument / Mission | Where Used in Game |
|---|---|---|---|
| **Celestial Bodies**<br>`/src/data/celestialBodies.json` | [JPL Horizons API](https://ssd.jpl.nasa.gov/api/horizons.api)<br>[NASA GSFC Planetary Fact Sheets](https://nssdc.gsfc.nasa.gov/planetary/factsheet/) | JPL Horizons API (live query) & SSD Group (`dataOrigin: "api"`) | Planetary physical properties (gravity, mass, radius, day/night length, temperatures, surface pressure, atmospheric composition) across all 6 Seasons and the 3D Solar System map. |
| **Landing Sites**<br>`/src/data/landingSites.json` | [NASA Artemis Candidate Landing Regions](https://www.nasa.gov/artemis-candidate-landing-regions/)<br>[LRO LOLA Science Team](https://lunar.gsfc.nasa.gov/) | LRO LOLA, LROC NAC, Mini-RF radar, Mars MOLA, MRO HiRISE (`dataOrigin: "factsheet-manual"`) | Elevation maps, slope hazards, annual solar illumination percentages (marked as approximate with citations to Mazarico 2011 Table 2/Fig 6, Bussey 1999 Fig 3, Gläser 2018 Fig 7, Colaprete 2010/2021, Apollo 11 ALSEP, Farley 2020), and cryogenic ice estimates. |
